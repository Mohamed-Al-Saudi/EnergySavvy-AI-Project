# Data Guide

## UCI Household Power Consumption

Primary use:
- Consumption analysis
- Forecasting target development
- Anomaly detection
- Sub-metering analysis

## Cairo Weather

Primary use:
- Independent weather exploration
- Cairo climate context
- Future localized system design

## Raw vs processed

`raw/` contains original downloaded files.

`processed/` contains files created by reproducible preprocessing scripts or notebooks.

Never manually overwrite raw source data.
