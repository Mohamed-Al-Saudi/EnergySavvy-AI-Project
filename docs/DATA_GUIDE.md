# Data Guide

## Overview

EnergySavvy AI uses two main categories of data:

1. **Historical data** for training, testing, and model development.
2. **Real-time application data** for the deployed dashboard.

Historical datasets are **not presented as real-time data** in the application.

---

## 1. UCI Household Power Consumption

The UCI Individual Household Electric Power Consumption dataset is historical electricity consumption data.

Primary use:
- Consumption analysis
- Forecasting model development
- Forecasting model training and testing
- Anomaly detection development
- Sub-metering analysis
- Feature engineering

The dataset is used as **offline historical training/testing data**.

It is not the live electricity source for the deployed dashboard.

---

## 2. Historical Cairo Weather

The Cairo weather dataset contains historical weather observations.

Primary use:
- Independent weather exploration
- Historical climate context
- Weather feature engineering
- Supporting model development and experimentation
- Future localized system design

The historical weather dataset is used as **offline analysis/training data**.

It is not the live weather source for the deployed dashboard.

---

## 3. Real-Time Weather API

The deployed application retrieves current weather information through a weather API.

Depending on availability, the application uses the detected or selected location to retrieve information such as:

- Temperature
- Humidity
- Wind speed
- Apparent temperature
- Weather conditions
- Latitude and longitude

This provides current localized weather conditions during dashboard operation.

---

## 4. Simulated Electricity Consumption Data

During the prototype stage, physical IoT electricity sensors are not available.

Therefore, EnergySavvy AI uses a **software-based energy consumption simulator** as a temporary replacement for real smart-meter/IoT readings.

The simulator continuously generates:

- Instantaneous power (kW)
- Voltage (V)
- Current (A)
- Appliance operating states
- Appliance-level power consumption
- Timestamps

The simulator models household appliance behavior and continuously produces new readings while the dashboard is running.

In a future deployment, the simulator can be replaced with real IoT or smart-meter data.

## 6. Raw vs Processed

`raw/` contains the original downloaded historical source datasets.

`processed/` contains files created through reproducible preprocessing scripts or notebooks.

Real-time weather data is retrieved from the weather API during application execution.

Real-time electricity data is generated by the energy simulator during application execution.

Neither real-time source replaces the historical training datasets.

Never manually overwrite raw source data.

---

## 7. Data Boundary

| Data Source | Purpose | Used as Live Dashboard Input? |
|---|---|---|
| UCI Household Power Consumption | Training, testing, historical analysis | No |
| Historical Cairo Weather | Training/development, historical analysis | No |
| Weather API | Current localized weather | Yes |
| Energy Consumption Simulator | Current simulated electricity readings | Yes |
| Real IoT/Smart Meter | Future production data source | Future |

**Key principle:** historical datasets train and support the AI models, while the deployed prototype operates using **current weather API data and continuously generated simulated electricity data**.
